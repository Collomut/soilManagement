# 🌱 ZERTHIVA: BENEATH THE LIVING EARTH
### Immersive 3D Soil Intelligence Experience · Inspired by Lusion.co

> *"Every signal begins beneath the surface."*

A world-class real-time 3D interactive scientific visualization of **Zerthiva**, the Soil Intelligence System (SIS). 

---

## 🌟 Overview & Key Features

1. **Central Living Organism & Geological Cutaway:**
   - Detailed procedural maize plant (*Zea mays*) with stalk, arching leaves, crown/brace roots, primary seminal taproot, lateral roots, and root tips.
   - Stratified soil horizons (Horizon O, Horizon A, Horizon B, Horizon C) with real-time vertical layer separation.
2. **10 Interactive Guided Chapters:**
   - **01 // The Living Surface:** Above-ground canopy inspection and daylight ambiance.
   - **02 // Descent Into Soil:** Subterranean descent revealing soil horizons O/A/B/C.
   - **03 // Plant Dissection:** Exploded plant anatomy (leaves, stem, crown, roots).
   - **04 // Hidden Water World:** Infiltration, pore redistribution, and root xylem water uptake.
   - **05 // Nutrient Chemistry:** Ion pathways ($NO_3^-$, $H_2PO_4^-$, $K^+$) with scientific distinction on bulk EC vs fertility.
   - **06 // The Sensor Reveal:** Subsurface probe inspection (dual EC electrode rings, FR4 capacitive blade, DS18B20 tip).
   - **07 // Hardware Assembly Explosion:** Exploded view of the $30 node (solar cap, RGB sentry beacon, ESP32 MCU, 18650 cell).
   - **08 // Monitoring Sequence:** 9-stage engineering pipeline from deep sleep to GSM/beacon dispatch.
   - **09 // The Decision Engine:** Zero-cloud local edge execution of Maas-Hoffman and FAO-56 algorithms.
   - **10 // The Experimental Test Lab:** Scenario testing with fault injection and deterministic pass/fail results.
3. **Signature Interaction: "Reveal the Hidden System":**
   - 12-stage continuous cinematic sequence orchestrating camera flight, soil opening, layer expansion, and hardware explosion.
4. **Lusion-Grade Design & Synthesized Audio:**
   - Web Audio API real-time synthesizer (55 Hz earthen drone, telemetry pings, water infiltration, alerts).
   - Minimalist spatial UI and fail-safe camera orientation controls.
